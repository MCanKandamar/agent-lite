description: Installs or updates agent-lite in a repository — AGENTS.md, docs/WORK.md and docs/PROJECT.md — so any coding agent can continue the project across sessions and tools and recover interrupted work from git. Runs a one-question-at-a-time setup interview that skips what it can read from the repo, supports embedded/firmware projects, stores cross-project user preferences once (~/.agents/USER.md), and picks or creates work profiles (~/.agents/profiles: code, embedded, learning, docs, or new ones through a short interview). Use when the user asks to set up, install, initialize, adopt or update agent-lite or the project working files, to change their agent preferences, or to create or change a profile.

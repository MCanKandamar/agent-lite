# Profile: docs
When: documents for people (CV, cover letters, reports, internship documents, presentations, guides).
<!-- agent-lite profile. Change only with the user's consent. -->

- Language: the document's own language (a Turkish CV stays Turkish). For a new document, ask once.
- Never invent facts: experience, dates, numbers, names, titles or results. If something is missing, ask, or leave a clearly marked placeholder.
- Keep the existing format, structure and tone unless asked. Before a large rewrite, show what will change (outline or before/after).
- Write for the named reader (recruiter, professor, company, customer): concrete over generic, short sentences, no filler or buzzwords.
- Before handing over: check spelling, consistent dates and terms, and length limits. For exported files (PDF, DOCX, PPTX), look at the rendered result.
- Personal data (ID numbers, phone, address) only where the document needs it.
